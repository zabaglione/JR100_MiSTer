# Console ModeのComputer系Load Game調査 対応表

| 出典 | 目的 | 具体対象 | 役割 | 前後関係 | 候補語 | 初出定義 |
|---|---|---|---|---|---|---|
| ユーザーの疑問、Console Mode公式設定 | メニュー項目が何を実行するかを区別する | Console Modeのゲーム一覧でファイルを選択した後、設定されたコアを起動して選択ファイルを渡そうとする操作 | 手段 | ゲームデータベース構築の後、コア側のファイル受理より前 | Load Game |  |
| Console Mode公式設定 | Computerカテゴリ全体と個別機種の能力を混同しない | `Computer.ini`内で機種ごとにコア実行ファイル、対象拡張子、検索ディレクトリを対応付ける記述 | 記録 | Console Modeの配布前に定義され、ゲームデータベース構築時に参照される | 機種別エントリ | 機種別エントリとは、`Computer.ini`で一つのComputerコアと対象ファイルを対応付ける節を指す。 |
| MiSTerコア実装、Console Mode実装 | JR-100とFDD対応コアの差を特定する | 起動後のコアがConsole Modeから渡された選択ファイルを自動的にマウントまたはロードできる接続 | 手段 | Console Modeによるコア起動の後、対象ソフトの実行より前 | 起動時メディア受け渡し | 起動時メディア受け渡しとは、Console Modeで選択したファイルを、起動したコアへ自動的にマウントまたはロードさせる接続を指す。 |
| Console Mode公式設定、MiSTerコア実装 | FDD装置のゲームが成立する条件を特定する | ディスクイメージを受け取れるComputerコアと、その拡張子・起動先を結ぶ機種別設定 | 開始条件 | 設定の配布後、利用者がLoad Gameでディスクイメージを選ぶ前 | FDD系ComputerコアのLoad Game条件 | FDD系ComputerコアのLoad Game条件とは、機種別エントリと起動時メディア受け渡しの両方が成立していることを指す。 |
| JR-100コア実装、実機観測 | JR-100で一覧表示と起動成功が分かれた理由を説明する | JR-100コアがOSD操作でPRG・BAS・テープを受け取る一方、Console Modeからの起動時ファイル受け渡しを処理できるかどうか | 状態 | JR-100がLoad Coreで起動した後、Load Gameで選択したプログラムを実行する前 | JR-100の起動時受理状態 | JR-100の起動時受理状態とは、現行コアがConsole Modeからの起動時メディア受け渡しを処理できるかを示す状態を指す。 |
| ユーザーによるJR-100コアの現状説明 | PRG・BASとテープの処理を分けて調査する | BASIC起動後、選択ファイルの内容をRAMへ直接書き込み、必要なポインタを更新するコア側の処理 | 手段 | BASIC起動の後、LISTまたはRUNの前 | PRG/BAS即時ロード | PRG/BAS即時ロードとは、BASIC起動後にプログラムファイルをRAMへ直接展開する現行コアの処理を指す。 |
| ユーザーによるJR-100コアの現状説明 | PRG・BASとテープの処理を分けて調査する | テープイメージを仮想カセットへ接続し、BASICのLOAD操作とテープ再生操作で読み込むコア側の処理 | 手段 | BASIC起動とLOAD入力の後、テープ上のデータ読込みの前 | テープマウント | テープマウントとは、テープイメージを仮想カセットへ接続し、JR-BASICのLOAD処理から読める状態にすることを指す。 |
| Console Mode Issue #20、SS1実機確認 | ホストへJR-100固有ランチャーを追加せずにLoad Gameを成立させる | `Computer.ini`でMGLを一覧へ出し、MGLがJR-100のRBFと`F1`または`F2`を指定する構成 | 手段 | ゲーム一覧の構築後、MiSTer Mainがファイルをコアへ転送する前 | MGLラッパー | MGLラッパーとは、選択ファイル自身に起動RBFと転送スロットを記述し、Console Modeホストの生ファイル対応表を迂回する方法を指す。 |
